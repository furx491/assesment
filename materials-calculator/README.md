# حاسبة الخامات المطلوبة للشراء

سكربت يحوّل ملف "قائمة الخامات لكل منتج" + "الأعداد المطلوبة" إلى قائمة شراء
جاهزة، إجمالية ومقسّمة على أقسام الإنتاج.

## المدخلات

ملف إكسل واحد فيه تابتان:

| التابة | المحتوى |
|---|---|
| `الخامات للمنتجات اريكة` | سطر لكل (منتج × خامة) مع القسم المستهلك والكمية للوحدة والوحدة. صف العناوين هو الصف 4. |
| `الاعداد ` | عمودان: اسم المنتج، العدد المطلوب إنتاجه. |

## التشغيل

```bash
pip install pandas openpyxl
python calc_materials.py المدخلات.xlsx احتياجات_الخامات.xlsx
```

## المخرجات

| التابة | المحتوى |
|---|---|
| `ملخص` | أرقام سريعة، الاحتياج حسب القسم، الإجمالي حسب الوحدة، أعلى 15 خامة. |
| `الإجمالي` | كل خامة مرة واحدة — الكمية الكلية المطلوب شراؤها. |
| `الإجمالي لكل قسم` | نفس الكميات موزّعة على أقسام الإنتاج (قائمة شراء كل قسم). |
| `فرعي - تفصيل المنتجات` | أصل الحساب: كل سطر منتج × خامة. |
| `ملاحظات ومشاكل البيانات` | أسطر ناقصة أو متعارضة في ملف المصدر تحتاج مراجعة بشرية. |

## طريقة الحساب

```
الكمية الإجمالية = الكمية للوحدة × العدد المطلوب من المنتج
```

ثم تُجمَّع الكميات على مستوى (الخامة، الوحدة) للإجمالي،
وعلى مستوى (القسم، الخامة، الوحدة) لقائمة كل قسم.

## قواعد مهمة

- **لا تُجمع الكميات عبر وحدات مختلفة.** الخامة المسجَّلة بالمتر وبالكيلو تظهر في سطرين
  منفصلين، وتُدرج في تابة الملاحظات لمراجعتها.
- **توحيد الأسماء:** أسماء الأقسام والوحدات المكتوبة بأكثر من صيغة (مثل `دهانات` و`الدهانات`،
  `علبه` و`علبة`) تُوحَّد قبل التجميع عبر `DEPT_MAP` و`UNIT_MAP`.
- **مطابقة المنتجات** بين التابتين تتجاهل الأقواس والمسافات الزائدة وحالة الأحرف.
  المنتجات بلا اسم إنجليزي تُربط يدويًا عبر `MODEL_TO_EN`.
- **الخامات بلا كود** تُجمَّع باسمها وتُدرَج في الملاحظات.
- منتج مطلوب بلا قائمة خامات، أو منتج له خامات بلا عدد مطلوب — لا يُحسب أيٌّ منهما،
  ويُذكر صراحةً في الملاحظات.

## تعديل الإعدادات

كل التوحيدات في أول الملف: `SHEET_MATERIALS`، `SHEET_COUNTS`، `HEADER_ROW`،
`DEPT_MAP`، `UNIT_MAP`، `MODEL_TO_EN`.

ملفات البيانات (`*.xlsx`) مستبعدة في `.gitignore` — المستودع عام.

## إضافة منتجات غير موجودة في ملف الإكسل

```bash
python calc_materials.py المدخلات.xlsx الناتج.xlsx \
  --extra-bom منتجات_اضافية_خامات.csv \
  --extra-counts منتجات_اضافية_اعداد.csv
```

- `--extra-bom` — أعمدة: `المنتج، كود المنتج، القسم، كود الخامة، اسم الخامة، الكمية للوحدة، الوحدة`
- `--extra-counts` — أعمدة: `اسم المنتج، العدد`

أكواد النظام الجديد تُكتب بالصيغة `RM-11003` / `FB-2127`؛ البادئة تُزال تلقائيًا
لتطابق الأكواد الرقمية في الملف القديم (`11003`).
