# خطة الإنتاج — مصنع الأثاث

جدولة إنتاج بطاقة محدودة (Finite Capacity Scheduling) لكل الأقسام.

## المخرج
`PRODUCTION_PLAN.xlsx` — 11 شيت:
SETTINGS · ORDERS · SCHEDULE · DAILY_PLAN · DEPT_LOAD · CAPACITY · CNC_QUEUE · OVERTIME · DELIVERY · FLOW · ISSUES

`review_v4.xlsx` — جداول المراجعة (المسارات، الطاقة، الأوقات التقديرية، المستبعدات).

## السكربتات
| الملف | الوظيفة |
|---|---|
| `stagemap.py` | توحيد 81 صيغة مرحلة مكتوبة كلام حر → مرحلة قياسية |
| `override.py` | مسارات أُمليت شفهياً (الترابيزة الجانبية، المرايا) |
| `est.py` | متوسطات الفئات للمنتجات اللي مالهاش مسار |
| `remain.py` | حساب الشغل الفاضل من المرحلة الحالية |
| `prio.py` | تصنيف الأولويات وربط خطة المعرض بأوامر التصنيع |
| `sched.py` | محرك الجدولة: تدفق قطعة قطعة + تجميع الفروع + طاقة محدودة |
| `build_out.py` | بناء الوركبوك النهائي (3 سيناريوهات + CNC + سهر) |

`python3 build_out.py` يبني الخطة كاملة.

## قواعد أساسية مطبّقة
- الشغل يتحرك **قطعة قطعة** — القسم التالي مايستناش الكمية كلها.
- **تجميع الفروع**: التشطيب مايبدأش غير لما كل الفروع تخلص.
- التفصيل والخياطة **يبدأوا بدري** بالتوازي (طاقة مستقلة 8 عمال).
- الحساب **من المرحلة الحالية** ورايح — اللي خلص مبيتحسبش.
- **الطاقة سقف مايتعداش** — الزيادة تترحّل، مفيش ضغط على الأرقام.
- CNC مورد مشترك بطابور مستقل (ماكينة واحدة).

## ناقص
مذكور في شيت ISSUES — أهمه 9 صفوف بدون وقت معياري، و319 وحدة بوقت تقديري.
